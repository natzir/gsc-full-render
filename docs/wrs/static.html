WRS static viewport test

Does the renderer stretch its viewport on a page with nothing dynamic? All the text below is in this page's HTML, over 10,000 px of it on a phone, with no images and nothing built or loaded by script. A script here, above the text, writes innerHeight once as the parser reaches it, then logs every resize and the size at the end of the body, at DOMContentLoaded, at load and after 1, 3, 6 and 10 s. It never changes the window or the layout. Run it in URL Inspection: the screenshot shows this top part, the HTML tab the whole log.

innerHeight at the top: script did not run

If the renderer stretches the viewport to the height of the page, the log shows a resize event and innerHeight then matches scrollHeight. Nothing on this page is loaded lazily, and it has no images, so no request depends on what enters the viewport. The log keeps the time of each reading in milliseconds since the page started, as performance.now() gives it in the renderer.

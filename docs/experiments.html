Googlebot rendering experiments

Test pages for how Google's renderer loads a page, made for GSC Full Fetch & Render. Run one in Search Console's URL Inspection, live or crawled: each page writes what it saw into its own rendered HTML, so the HTML tab of the tested page shows the result.

The renderer's viewport

wrs/: how far the viewport reaches down the page and across it, logged as it changes, and which loading="lazy" images Googlebot requests, down the page and along a carousel. ?h= sets how tall the page is.

  • 200,000 px tall
  • 20,000,000 px tall
  • 1,000,000 px of real text instead of empty blocks, and the same with content-visibility: hidden

wrs/static.html: the same reading on a static page, over 10,000 px of text all in its HTML and nothing built by script: innerHeight read once at the top, as the parser reaches it, then every resize.

How much HTML it keeps

wrs/2mb.html: a 3 MB HTML file with markers of their byte offset, to see how much of it Googlebot reads and URL Inspection shows.

wrs/size.html: a rendered HTML of a set number of paragraphs and kilobytes, of random or repeated words, to see what decides where the HTML tab stops.

  • 3 MB in 200 paragraphs
  • 3 MB in 50,000 paragraphs of one word

wrs/nodes.html: which DOM nodes count toward that point.

  • 120,000 empty elements
  • 60,000 comments, each with a paragraph

wrs/nodes-index.html: a static page of 150,000 DOM nodes with made-up words at known nodes, to see which of them Google indexes.
